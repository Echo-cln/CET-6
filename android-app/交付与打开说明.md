# 溯·辞 Android App 完整工程：交付与打开说明

## 本压缩包包含的内容

- 完整 Android Studio 工程源码：`app/`、Gradle 配置、资源与 WebView 逻辑；
- 标准 Gradle Wrapper：`gradlew`、`gradlew.bat`、`gradle/wrapper/gradle-wrapper.jar`、`gradle-wrapper.properties`；
- 已随包附带的 Gradle 8.9 发行包：`gradle-offline/gradle-8.9-bin.zip`。

因此，Android Studio 不会再因为从 `services.gradle.org` 下载 Gradle 而卡住。此前手动下载的 `gradle-9.3.0-bin.zip` 不适用于本工程：本工程的 Android Gradle Plugin 8.7.3 与 Gradle 8.9 对应。

## 唯一正确的解压位置

将压缩包内的 `android-app` 文件夹替换到：

```text
E:\Programs\su-ci-vocabulary-source\android-app
```

不要额外套一层同名文件夹；打开后应直接看到 `app`、`gradle`、`gradlew.bat`、`settings.gradle.kts`。

## 在 Android Studio 中打开

1. 选择 **Open**；
2. 选择 `E:\Programs\su-ci-vocabulary-source\android-app`；
3. 等待首次 Sync。

首次 Sync 不会下载 Gradle 本体，因为 Wrapper 已指向压缩包内的本地 Gradle 8.9。若 Android Studio 提示安装 Android SDK Platform 35，按提示安装即可。

Android Gradle Plugin 与 AndroidX 组件是 Android 官方构建依赖，若此电脑从未构建过 Android 项目，首次同步仍可能需要下载它们一次；这是**电脑编译阶段**的依赖，不是手机 App 的运行依赖。

## 安装到手机

菜单选择 **Build → Build APK(s)**。构建成功后选择 *locate*，将下列文件发给手机：

```text
app\build\outputs\apk\debug\app-debug.apk
```

在 Android 手机上允许“从此来源安装应用”后安装。

安装后的 App 打开的是：

```text
https://su-ci-vocabulary-cn-dp6l9gl9cvqw.edgeone.dev
```

因此它使用国内镜像、同一个账号和学习记录；手机端不需要 Gradle、不需要 Android Studio，也不需要梯子。网页端的内容更新会直接显示在 App 中，无需重新安装 APK。
