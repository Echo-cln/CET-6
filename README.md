# 溯·辞 | SuCi Vocabulary

## 六级词汇·每日背诵

溯·辞是一款面向大学英语六级学习的个人词汇管理网站，帮助学习者通过结构化词义、搭配、例句和复习记录，建立长期词汇记忆。

## 核心功能

- 1800+ 六级核心词汇管理
- 每日新词与复习任务
- 熟练度追踪
- 收藏与重点表达积累
- 英美音标展示
- 高频搭配与例句学习
- 学习历史记录

## 技术栈

- Next.js
- TypeScript
- Tailwind CSS
- Supabase

## 本地运行

```bash
npm install
npm run dev
```

## 项目理念

溯·辞中的“溯”代表追溯词义来源，“辞”代表语言表达。
希望通过理解词汇，而不是机械重复，提升英语长期能力。
